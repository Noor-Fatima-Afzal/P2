# Noor Fatima | Biomedical AI Engineering

An independently deployable static research portfolio focused on medical imaging, biomedical signals, clinical AI, and reproducible ML systems.

## Run
`npm run build` creates `dist/`. Serve `dist/` with any static host.

## GitHub Pages
The included GitHub Actions workflow builds `dist/` and deploys it to `https://noor-fatima-afzal.github.io/P2/` on pushes to `main`.
